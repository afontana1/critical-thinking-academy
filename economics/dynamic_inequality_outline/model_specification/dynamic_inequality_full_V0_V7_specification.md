# Dynamic Inequality Systems Model

## Complete Computational Specification: V0-V7

**Document status:** implementation baseline 1.0  
**Model class:** discrete-time, group-based system dynamics model  
**Default time step:** one year  
**Default simulation horizon:** 50 years for intragenerational tests; 100-150 years for intergenerational tests  
**Primary purpose:** explain and test how unequal stocks alter subsequent accumulation, opportunity, mobility, policy, and institutional dynamics.

> No model element is admissible unless it has a theoretical rationale, a mathematical definition, a unit, an initialization rule, a verification test, and a calibration plan.

---

## 1. How to use this specification

This document is the implementation contract linking the research theory to the computational model. It specifies all planned phases from V0 through V7. Later empirical work may revise parameter values and, when evidence requires it, functional forms. Structural changes must be recorded as specification changes rather than introduced silently in code.

The model should be built cumulatively. Each version inherits the verified structure of the previous version and adds one coherent subsystem. A version may be promoted only when its required tests pass. The complete model is therefore not one indivisible program; it is a nested sequence of models that can be compared, disabled, and independently validated.

### 1.1 Authority order

1. Theoretical proposition
2. Model specification
3. Software implementation
4. Pseudo-data verification
5. Empirical calibration
6. Validation and policy analysis

When code and this specification disagree, the code is presumed wrong until the specification is deliberately amended.

### 1.2 Recommended first computational representation

The baseline implementation uses population groups indexed by $g=1,\ldots,G$. These may represent wealth quintiles, socioeconomic strata, regions, demographic groups, or combinations chosen for a specific empirical application. Each group has a population share $n_g(t)$ and a vector of average or representative state variables.

The group representation is preferred initially because it preserves distributional structure while keeping stocks, flows, accounting, and feedback loops transparent. A household-level agent-based extension is possible later, but is not required to implement or test the theory.

### 1.3 Global conventions

- Time is discrete and indexed by $t$.
- Unless otherwise specified, flows are annual quantities and rates are annual rates.
- Monetary values are real currency units in a common base year.
- Stocks are measured at the start of each period; flows occur during the period; new stocks are recorded at the end.
- All probabilities remain in $[0,1]$.
- Nonnegative stocks may not become negative through numerical error.
- Stochastic simulations must accept and record a random seed.
- Every output dataset must include model version, parameter-set identifier, scenario identifier, seed, and timestamp.

## 3. Shared state, indexing, and accounting

### 3.1 State vector

The complete group-level state vector is

$$
\mathbf{x}_g(t)=\left[A_g,D_g,C_g,H_g,S_g,N_g,P_g\right],
$$

with system-level institutional states

$$
\mathbf{z}(t)=\left[L(t),U(t),SC(t)\right].
$$

Where:

- $A_g$: assets
- $D_g$: debt
- $C_g$: credit reputation or access capacity
- $H_g$: human capital
- $S_g$: effective service quality or access
- $N_g$: network and social capital
- $P_g$: political influence
- $L$: institutional legitimacy
- $U$: instability or disruption
- $SC$: state capacity

Net wealth is always derived:

$$
W_g(t)=A_g(t)-D_g(t).
$$

### 3.2 Population weights and aggregate quantities

Group shares satisfy

$$
\sum_g n_g(t)=1, \qquad n_g(t)\ge 0.
$$

For a group variable $X_g$, the population-weighted mean is

$$
\bar X(t)=\sum_g n_g(t)X_g(t).
$$

Between-group dispersion may be summarized by weighted variance, ratios, top shares, or a grouped-data approximation to the Gini coefficient. The software must retain the full group distribution and must not use a single inequality statistic as a substitute for state variables.

### 3.3 Government budget modes

The model must support two budget modes:

**Closed budget mode**

$$
\sum_g n_g Tax_g(t)+Rev^{other}(t)+GovBorrow(t)
=
\sum_g n_g Tr_g(t)+PubInv(t)+Insurance(t)+DebtService^{gov}(t).
$$

**Open or externally financed mode** permits an explicit residual $ExternalFinance(t)$. No unexplained residual is allowed.

### 3.4 Period update order

Unless a version overrides it, each period follows this sequence:

1. Read beginning-of-period stocks and exogenous scenario inputs.
2. Compute aggregate and distributional indicators.
3. Determine policy rules and government budget allocations.
4. Compute labor and capital income.
5. Compute taxes, transfers, disposable resources, and consumption needs.
6. Compute credit limits, borrowing costs, borrowing demand, repayment, and default.
7. Compute investment and other stock flows.
8. Apply shocks, depreciation, and losses.
9. Update stocks simultaneously.
10. Apply cohort turnover and intergenerational transitions when active.
11. Validate bounds and accounting identities.
12. Record outputs.

Functions must use beginning-of-period values unless explicitly marked as simultaneous or lagged. This avoids accidental algebraic loops.

### 3.6 Shared numerical rules

- Use 64-bit floating-point arithmetic at minimum.
- Default bound handling is smooth saturation in equations; clipping is a final safety assertion, not the primary behavioral mechanism.
- A flow out of a stock may not exceed the available stock in one time step.
- Debt repayment may not exceed beginning debt plus current-period interest and borrowing unless refinancing is explicitly modeled.
- Transition matrices must be normalized by a numerically stable softmax or equivalent construction.
- Missing empirical values may not be silently replaced. Imputation rules must be recorded in calibration metadata.
- The default deterministic solver is explicit annual difference equations. A smaller time-step comparison must be available for stability testing.

# V0 - Accounting Sandbox

## V0.1 Purpose

Establish exact balance-sheet, income, fiscal, and flow accounting before introducing endogenous behavioral feedback.

## V0.2 Frozen scope

- Assets, debt, net wealth, labor income, exogenous capital income, taxes, transfers, consumption, saving, borrowing, repayment, asset purchases, asset losses, and government budget accounting.
- All behavioral rates are fixed inputs or scenario series.
- No credit-price feedback, human capital, services, mobility, politics, or institutional dynamics.

## V0.3 Active stocks

- $A_g$: assets
- $D_g$: debt

## V0.4 Auxiliary variables and controls

- $W_g=A_g-D_g$
- $Y^L_g$: exogenous labor income
- $Y^K_g$: exogenous capital income
- $Tax_g$, $Tr_g$, $Cns_g$, $Sav_g$

## V0.5 Governing equations


$$Y_g(t)=Y^L_g(t)+Y^K_g(t)+Tr_g(t)-Tax_g(t)$$

$$Resources_g(t)=Y_g(t)+B_g(t)$$

$$Sav_g(t)=\max\{0,Resources_g(t)-Cns_g(t)-Rep_g(t)\}$$

$$A_g(t+1)=A_g(t)+AssetBuy_g(t)-AssetLoss_g(t)$$

$$D_g(t+1)=D_g(t)+B_g(t)+IntDebt_g(t)-Rep_g(t)-WriteOff_g(t)$$

$$W_g(t+1)=A_g(t+1)-D_g(t+1)$$

## V0.6 Initialization specification

- Provide deterministic arrays for each group.
- Default pseudo-data: five equal-size groups with monotonic assets, non-monotonic debt, and equal labor income.
- Create a second fixture with identical groups for invariance testing.

## V0.7 Minimum parameter catalog

| Symbol | Meaning | Unit | Pseudo-data default |
|---|---|---|---|
| tau0 | fixed effective tax rate | 1/year | 0.20 |
| c0 | fixed consumption share | dimensionless | 0.75 |
| rD0 | fixed debt interest rate | 1/year | 0.05 |
| loss0 | asset-loss rate | 1/year | 0.01 |

## V0.8 Required outputs

- All beginning and ending stocks
- Every named flow
- Income components
- Government sources and uses
- Accounting residuals

## V0.9 Verification suite

- [ ] Net wealth identity holds to $10^{-10}$ relative tolerance.
- [ ] No flow exceeds its available source.
- [ ] Closed government budget residual is below $10^{-10}$.
- [ ] Identical inputs produce bitwise-identical outputs where platform permits.
- [ ] Equal groups remain equal.
- [ ] Zero-flow fixture leaves all stocks unchanged.
- [ ] One-period hand calculation matches code.

## V0.10 Calibration and empirical mapping

- Use realistic magnitudes only to catch scaling errors.

## V0.11 Promotion gate

> All accounting and reproducibility tests pass; no unexplained residuals or negative stocks.

# V1 - Minimal Cumulative Wealth Model

## V1.1 Purpose

Test the central asset-accumulation mechanism and the capacity of taxes and transfers to balance it.

## V1.2 Frozen scope

- Adds endogenous capital income, saving, asset investment, depreciation, heterogeneous returns, and redistribution.
- Retains exogenous labor income.
- Implements reinforcing loop R1 and balancing tax-transfer loops.

## V1.3 Active stocks

- Inherited V0: $A_g,D_g$

## V1.4 Auxiliary variables and controls

- Return rate $r^A_g$
- Disposable income
- Saving propensity
- Investment
- Inequality measures

## V1.5 Governing equations


$$Y^K_g(t)=r^A_g(t)A_g(t)$$

$$Y^{disp}_g(t)=Y^L_g(t)+Y^K_g(t)+Tr_g(t)-Tax_g(t)-Rep_g(t)$$

$$s_g(t)=\sigma\left(\alpha_s+\beta_W\log(1+\max(W_g,0))+\beta_Y\log(1+\max(Y^{disp}_g,0))\right)$$

$$I^A_g(t)=s_g(t)\max(Y^{disp}_g(t),0)$$

$$A_g(t+1)=A_g(t)+I^A_g(t)+r^{app}_g(t)A_g(t)-\delta_A A_g(t)-Loss^{shock}_g(t)$$

A baseline progressive tax rule is

$$Tax_g(t)=\tau_Y(Y_g)Y_g+\tau_W(W_g)\max(W_g,0),$$

with transfers allocated through an explicit rule that satisfies the selected government-budget mode.

## V1.6 Initialization specification

- Use the V0 fixtures plus log-spaced asset holdings.
- Run equal-return and heterogeneous-return cases.
- Set debt to zero in the simplest R1 isolation run.

## V1.7 Minimum parameter catalog

| Symbol | Meaning | Unit | Pseudo-data default |
|---|---|---|---|
| rA_base | baseline capital return | 1/year | 0.04 |
| rApp | asset appreciation | 1/year | 0.01 |
| deltaA | asset depreciation/loss | 1/year | 0.01 |
| alpha_s | saving intercept | dimensionless | -1.0 |
| beta_W | wealth effect on saving | dimensionless | 0.15 |
| tauY | income tax schedule | dimensionless | scenario |
| tauW | wealth tax schedule | 1/year | scenario |

## V1.8 Required outputs

- Wealth and asset paths by group
- Capital-income share
- Saving and investment rates
- Gini/top-share/group-gap measures
- Tax and transfer incidence
- Loop-isolation comparisons

## V1.9 Verification suite

- [ ] R1 disabled: setting returns and appreciation to zero removes return-driven divergence.
- [ ] Equal-state invariance under equal parameters.
- [ ] Monotonicity: raising $r^A_g$ weakly raises terminal assets absent offsetting policy.
- [ ] Full confiscatory return tax neutralizes net capital return in a controlled fixture.
- [ ] No-tax/no-transfer and balanced redistribution fixtures match analytic expectations.
- [ ] Time-step sensitivity using half-year steps stays within a declared 1% terminal-stock tolerance for smooth cases.

## V1.10 Calibration and empirical mapping

- SCF asset stocks, income, saving, and portfolio composition.
- National accounts or asset-class return series.
- Tax and transfer incidence data.
- Pseudo-data parameter recovery before real estimation.

## V1.11 Promotion gate

> R1 and balancing policy loops are independently switchable, analytically understandable, and numerically stable.

# V2 - Credit, Debt, and Financial Fragility

## V2.1 Purpose

Represent unequal borrowing access, borrowing price, productive and defensive borrowing, repayment, default, and asset liquidation.

## V2.2 Frozen scope

- Adds credit reputation/access capacity, endogenous borrowing limits and interest rates, productive and defensive credit demand, debt burden, delinquency, default, write-off, and collateral loss.
- Implements reinforcing credit loop R2 and debt/precarity loop R4.

## V2.3 Active stocks

- $A_g,D_g$
- $C_g$: credit reputation/access capacity

## V2.4 Auxiliary variables and controls

- Borrowing limit
- Interest rate
- Debt-service ratio
- Liquidity need
- Productive investment opportunity
- Default probability
- Collateral seizure

## V2.5 Governing equations


$$Limit_g(t)=\max\left\{0,\lambda_0+\lambda_A A_g+\lambda_Y Y_g+\lambda_C C_g\right\}$$

$$r^D_g(t)=r^{market}(t)+\rho_0+\rho_D\frac{D_g}{Y_g+\epsilon}-\rho_A\frac{A_g}{Y_g+\epsilon}-\rho_C C_g$$

$$B_g(t)=\min\{Limit_g(t)-D_g(t),\ B^{prod}_g(t)+B^{def}_g(t)\}_+$$

$$DSR_g(t)=\frac{RepSched_g(t)+r^D_g(t)D_g(t)}{\max(Y^{gross}_g(t),\epsilon)}$$

$$p^{def}_g(t)=\sigma\left(\gamma_0+\gamma_D DSR_g+\gamma_L LiquidityGap_g-\gamma_C C_g\right)$$

$$Default_g(t)=p^{def}_g(t)\,D_g(t)$$

$$C_g(t+1)=\operatorname{clip}_{[0,1]}\left[C_g+\eta_R RepSuccess_g-\eta_M Delinquency_g-\eta_F p^{def}_g\right]$$

$$D_g(t+1)=D_g+B_g+r^D_gD_g-Rep_g-WriteOff_g$$

$$A_g(t+1)=A_g+I^{own}_g+I^{credit}_g+App_g-Dep_g-Liquidation_g-CollateralLoss_g.$$

## V2.6 Initialization specification

- Construct households/groups with equal net wealth but different asset-debt compositions.
- Create high- and low-credit-reputation fixtures.
- Generate income shocks with known timing and magnitude.

## V3.4 Auxiliary variables and controls

- Experience accumulation
- Labor productivity
- Labor income

## V3.5 Governing equations


$$I^H_g(t)=\kappa_E EduInv_g(t)^{\alpha_E}S_g(t)^{\beta_E}+\kappa_X Exp_g(t)+\kappa_{health}HealthInv_g(t)$$

# V4 - Intergenerational Transmission and Mobility

## V4.1 Purpose

Translate parent states into descendant initial conditions and explicit socioeconomic transition probabilities.

## V4.2 Frozen scope

- Adds cohorts or generations, inheritance and gifts, childhood investment/exposure, cohort replacement, and a row-stochastic mobility transition matrix.
- Implements reinforcing intergenerational loop R6.
- Mobility is measured from transitions and rank changes, never stored as a stock.

## V4.3 Active stocks

- All inherited group stocks by cohort
- Population shares $n_{g,c}$

## V4.4 Auxiliary variables and controls

- Asset transfer
- Debt exposure
- Child human-capital endowment
- Service exposure
- Transition matrix $M_{ij}$
- Birth and cohort-exit rates

## V4.5 Governing equations


$$Inh^A_{child,g}=\tau_A(1-estateTax_g)A_{parent,g}$$

$$H^{init}_{child,g}=\operatorname{clip}_{[0,1]}\left[h_0+\chi_HH_{parent,g}+\chi_SS_{child,g}+\chi_IChildInv_g\right]$$

Define destination scores

$$q_{ij}=\alpha_j+\beta_{jO}O_i+\beta_{jH}H_i+\beta_{jW}\tilde W_i+\beta_{jS}S_i+\Gamma_j Institutions,$$

then

$$M_{ij}=\frac{\exp(q_{ij})}{\sum_k\exp(q_{ik})}.$$

Cohort shares update as

$$n^{new}_j(t+1)=\sum_i n^{parent}_i(t)M_{ij}(t).$$

Initial descendant stocks are conditional expectations or sampled distributions based on parental states, transition destination, and policy.

## V4.6 Initialization specification

- Create parent cohorts with known states and a known synthetic transition matrix.
- Use generation intervals such as 25 years while financial stocks continue annually.
- Support deterministic expected-value and stochastic cohort-sampling modes.

## V4.7 Minimum parameter catalog

| Symbol | Meaning | Unit | Pseudo-data default |
|---|---|---|---|
| tau_A | transfer fraction | dimensionless | 0.5 |
| estateTax | estate tax schedule | dimensionless | scenario |
| chi_H | parent-H persistence | dimensionless | 0.3 |
| chi_S | service exposure effect | dimensionless | 0.3 |
| beta_j* | transition-score coefficients | dimensionless | synthetic then estimated |
| genLength | generation interval | years | 25 |

## V4.8 Required outputs

- Transition matrices
- Absolute and relative mobility
- Rank-rank association
- Intergenerational elasticities
- Inherited asset and human-capital shares
- Channel-specific persistence contributions

## V4.9 Verification suite

- [ ] Every transition probability is in $[0,1]$ and each row sums to one within $10^{-12}$.
- [ ] Population shares remain nonnegative and sum to one.
- [ ] Identity transition fixture reproduces parent distribution.
- [ ] Uniform transition fixture removes origin dependence.
- [ ] Disabling inheritance removes only asset-transfer channel.
- [ ] Synthetic transition parameters are recoverable under identified fixtures.
- [ ] Annual and generational clocks synchronize without double updating.
- [ ] V4 reduces to V3 when cohort turnover and transmission are disabled.

## V4.10 Calibration and empirical mapping

- Opportunity Insights or equivalent mobility matrices.
- PSID parent-child income, wealth, and education links.
- Inheritance and inter vivos transfer data.
- Neighborhood and childhood-exposure estimates.

## V4.11 Promotion gate

> Cohort accounting and transition probabilities are exact; each transmission channel is independently switchable and empirically mappable.

# V5 - Networks and Political Allocation

## V5.1 Purpose

Add accumulated network access and political influence that operate through explicit opportunity and policy channels.

## V5.2 Frozen scope

- Adds network capital, political influence, organized countervailing power, endogenous tax/transfer/public-investment parameters, and policy allocation.
- Implements network reinforcement and political-allocation loop R5.
- Political influence may not directly alter wealth or returns except through a declared institutional rule.

## V5.3 Active stocks

- $N_g$: network capital
- $P_g$: political influence share

## V5.4 Auxiliary variables and controls

- Job and investment matching
- Political investment
- Counter-mobilization
- Policy weights
- Endogenous tax, transfer, regulation, and service-allocation rules

## V5.5 Governing equations


$$N_g(t+1)=\operatorname{clip}_{[0,1]}\left[N_g+Form_g-MaintLoss_g-Exclusion_g\right]$$

$$Match_g(t)=\sigma(m_0+m_HH_g+m_NN_g+m_SS_g).$$

Raw political capacity is

$$\tilde P_g(t+1)=(1-\delta_P)P_g+\phi_W f(W_g)+\phi_NN_g+Org_g-Counter_g,$$

and influence shares are normalized:

$$P_g(t+1)=\frac{\max(\tilde P_g,0)}{\sum_k\max(\tilde P_k,0)+\epsilon}.$$

A generic policy rule is

$$Policy_k(t)=Policy_k^{base}+\psi_k\sum_g P_g(t)Preference_{gk}+DemocraticConstraint_k(t).$$

Public service allocation must satisfy

$$\sum_g PubInv^S_g(t)=PubInv(t),$$

with allocation shares generated by a transparent function of need, population, political influence, and statutory constraints.

## V5.6 Initialization specification

- Use equal-network/equal-influence fixtures.
- Create wealth-different but preference-identical groups to isolate resource-to-influence mapping.
- Create influence-different groups with fixed policy preferences to isolate allocation effects.

## V6.1 Purpose

## V6.5 Governing equations


$$Fair(t)=\sigma\left(f_0-f_I Inequality(t)-f_GPolicyGap(t)-f_SServiceGap(t)+f_MMobility(t)\right)$$

# 6. Parameter governance

Every parameter record must contain:

- symbol and plain-language definition;
- equation and subsystem;
- unit and valid range;
- sign expectation;
- pseudo-data default;
- empirical source or prior;
- estimation/calibration method;
- uncertainty distribution;
- correlation with other parameters;
- version first activated;
- sensitivity ranking;
- change history.

Parameters must be stored outside source code in versioned machine-readable files such as YAML, JSON, or Parquet. The simulator may not contain unexplained numeric literals other than numerical tolerances.

## 6.1 Parameter classes

1. **Accounting parameters:** conversion factors and timing conventions.
2. **Behavioral parameters:** saving, borrowing, repayment, investment, and matching responses.
3. **Technological parameters:** production and accumulation elasticities.
4. **Institutional parameters:** tax schedules, policy responsiveness, state capacity, and constraints.
5. **Transition parameters:** mobility and intergenerational persistence.
6. **Shock parameters:** frequency, magnitude, duration, and covariance.
7. **Measurement parameters:** mappings from observed variables to latent indices.

# 7. Pseudo-data design

Pseudo data serve three different purposes and should be stored separately.

## 7.1 Deterministic fixtures

Small arrays with hand-computable results for accounting, symmetry, bounds, and edge cases. These are unit-test data, not simulated populations.

## 7.2 Synthetic populations

Generate correlated group or household attributes using a latent rank variable $z$:

$$
\log(A+1)=a_0+a_1z+\epsilon_A,
$$

$$
D=d_0+d_1\max(-z,0)+d_2A+\epsilon_D,
$$

$$
H=\sigma(h_0+h_1z+\epsilon_H),\qquad
S=\sigma(s_0+s_1z+\epsilon_S).
$$

The covariance matrix and random seed must be saved. Independent draws are prohibited for the main synthetic baseline because they erase theoretically important correlations.

## 7.3 Synthetic truth datasets

Run the model with known parameters, add controlled measurement error, and then apply the intended estimation pipeline. These datasets test identifiability and parameter recovery.

# 8. Calibration specification

## 8.1 Calibration hierarchy

1. Directly observed initial states.
2. Parameters estimated from microdata or quasi-experimental evidence.
3. Parameters inferred by matching dynamic moments.
4. Literature-informed priors.
5. Explicitly uncertain structural parameters explored through scenarios.

## 8.2 Target moments

The full target set may include:

- asset and debt distributions;
- gross and net balance-sheet positions;
- labor and capital income distributions;
- saving and investment rates;
- borrowing rates, interest spreads, debt service, delinquency, and default;
- human-capital, service, and earnings gradients;
- intergenerational transition matrices and rank-rank relationships;
- tax and transfer incidence;
- public-service allocation;
- political influence proxies and policy responsiveness;
- legitimacy, capacity, and disruption indicators.

## 8.3 Objective function

A normalized weighted-moment loss is

$$
\mathcal{L}(\theta)=\sum_{m=1}^{M}w_m
\left(\frac{\mu_m^{sim}(\theta)-\mu_m^{obs}}{s_m}\right)^2,
$$

where $s_m$ is a scale such as the observed standard error or a substantively meaningful tolerance. Bayesian calibration may replace or supplement optimization. Weights and scales must be declared before viewing policy results.

## 8.4 Identification requirements

- Perform synthetic parameter recovery for every proposed estimator.
- Report posterior or sampling correlations among parameters.
- Profile weakly identified parameters.
- Compare reduced and expanded models.
- Do not interpret a calibrated parameter causally unless supported by identification outside the model.

# 9. Validation and robustness

Validation is layered:

1. **Structural validation:** equations and boundaries are theoretically plausible.
2. **Dimensional validation:** every equation is unit-consistent.
3. **Code verification:** implementation matches equations.
4. **Behavior reproduction:** model matches multiple historical patterns simultaneously.
5. **Holdout validation:** fit is tested on unused periods, cohorts, regions, or outcomes.
6. **Sensitivity analysis:** local and global sensitivity are reported.
7. **Structural uncertainty:** alternative functional forms and boundaries are compared.
8. **Policy robustness:** conclusions persist across plausible parameter and structural sets.

Minimum global methods should include Morris screening or equivalent for high-dimensional triage and Sobol or variance-based indices for the smaller influential set. Parameter uncertainty, initial-state uncertainty, stochastic uncertainty, and model-structure uncertainty must be distinguished.

# 13. Implementation sequence and completion definition

## 13.1 Recommended sequence

1. Implement common state containers, units, configuration, and output schema.
2. Implement V0 and its deterministic fixtures.
3. Implement V1 and analytic loop-isolation experiments.
4. Implement V2 with gross-balance-sheet fixtures and shocks.
5. Implement V3 with delayed stock formation and correlated pseudo data.
6. Implement V4 with separate annual and generational clocks.
7. Implement V5 with explicit graph-level checks preventing direct political shortcuts.
8. Implement V6 as an optional conditional module with alternative threshold specifications.
9. Implement V7 scenario, calibration, uncertainty, and reporting infrastructure.

## 13.2 Definition of complete implementation

The entire V0-V7 model is considered implemented only when:

- every variable in the master dictionary is represented or explicitly deferred;
- every governing equation has a tested software implementation;
- every version can run independently;
- lower-version reduction tests pass from the V7 codebase;
- pseudo-data verification and synthetic recovery pass;
- all monetary and population accounting closes;
- every result is reproducible from a run manifest;
- calibration targets and uncertainty are recorded;
- policy experiments change only declared levers;
- documentation and code use consistent notation.

## 13.3 Change-control rule

Any change to a stock, flow, equation, timing convention, unit, boundary, or policy channel requires:

1. a specification change note;
2. an updated theory-to-model traceability row;
3. an updated variable or parameter dictionary;
4. at least one new or modified verification test;
5. a versioned migration note for existing calibration files.
